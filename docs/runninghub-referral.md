## English

**Referral disclosure:** the registration link and QR code contain affiliate referral code `qqgzxufp`. The referrer may receive a reward. No discount or credit offer is promised. Service fees, credits and offers are determined by RunningHub’s current terms.

[Register for RunningHub via the referral link](https://www.runninghub.ai?inviteCode=qqgzxufp)

The QR code encodes that same URL. It is native vector geometry: no script, no external image, no tracking pixel and no automatic redirect. It was generated with segno 1.6.6: `make_qr(url, error='m', boost_error=False)`, then `save(kind='svg', scale=1, border=4, unit='mm', xmldecl=False, svgns=True)`, with the title “RunningHub registration referral QR code” and a description that names referral code `qqgzxufp` and states it is an affiliate referral, not an API key. `role="img"` is set on the root `<svg>`. Those parameters reproduce the file.

How the RunningHub lane submits the same graph and checks the account is documented in [hosted compute](hosted-compute.md).
