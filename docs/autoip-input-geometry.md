# AutoIP H3 首尾格上傳幾何

一般圖生影片、角色首格影片和 pipeline 交接共用 AutoIP worker 的輸入轉接。只有明確選擇 `480p`、`16:9` 的 `image_to_video` 新計畫會加入版本化的 `frame_fit=contain-black-h3-480p-v1`。worker 先驗證原素材的所有權、角色綁定及 SHA-256，再製作 864×480 的等比例置中黑邊衍生檔；不裁切、不改寫原圖。這個像素畫布來自已觀察的 AutoIP H3 輸出，沒有把所有供應商的 `16:9` 標籤推定成同一尺寸。

相同比例的來源保留原始位元組；其他來源以 Lanczos 縮放後補黑邊，透明區合成黑色。EXIF 方向先正規化。動漫與寫實使用相同幾何程序，原有視覺類別與角色權限保持不變。多參考影片、圖片編輯及其他操作不使用這個程序。

`9:16`、`768p`、`2k` 等未驗證畫布維持原圖提交，預覽明示本次比例修正不涵蓋；沒有猜測尺寸或取消原有支援。已受理的舊工作若沒有 `frame_fit`，繼續使用原圖。舊 v4 角色授權只在原有綁定完全吻合且未新增此選項時相容；不能用它授權新轉接。新 I2V profile revision 為 `autoip-0.4.0-options-v5-frame-fit`。

每個 owner／durable request／素材欄位都有 `castle.autoip-input-geometry.v1` 收據，分別記錄 canonical source 的 asset ID、SHA、視覺類別、角色 IDs、尺寸，以及 upload 的 SHA、尺寸、MIME、補邊參數。原 intent、素材版本和 pipeline dependency hash 指向原圖，不能改成衍生檔的雜湊。`frame_fit` 是本機計畫選項，送到 AutoIP 的 multipart 不包含它。

衍生檔與收據先以原子方式持久化，之後才可送出。再次準備相同 request 時重新驗證原素材、收據綁定與衍生檔 SHA，重用相同位元組；不再次縮放、不允許換來源。檔案為0600，owner／request 目錄為0700。這不授權重送工作：既有 durable worker 與 client guard 繼續阻止已送出或結果不明的 UUID 重複提交。

`AutoIPSubmissionProcessor` 保留原 constructor 用法，僅在有新選項時延遲建立轉接器。可用 `input_geometry_root` 或 `CASTLE_AUTOIP_INPUT_GEOMETRY_ROOT` 指定持久目錄；預設是 `${XDG_CACHE_HOME:-~/.cache}/castle-comfy-web/autoip-input-geometry`。受 systemd 寫入限制的部署需設定可寫入的持久目錄。此目錄保存處理證據，不應在工作結果不明時當一般暫存清除。

離線測試使用合成圖片、假 transport 和既有授權／交接程式，涵蓋直式、方形、寬幅、原比例 identity、首尾順序、EXIF、透明圖、來源不變、重試重用、竄改拒絕、舊計畫、未知畫布與單次提交。黑邊會成為模型條件；沒有保證模型不延展黑邊、全片比例或人物、衣著、背景保真。

## 2026-11-10 實際生成與抽樣結果

新轉接已完成三次 AutoIP 實際生成：一般動漫方形來源1024×1024、一般寫實直式來源864×1152，以及角色綁定的動漫方形來源1024×1024。三案均產生864×480、124格、24fps、約5.167秒的影片，並從實際製作介面的各自任務卡點開成果，通過瀏覽器影片解碼；沒有前端 JavaScript 錯誤。

三案逐筆核對了已授權 canonical source、不可變計畫及 worker 補邊收據：原圖 SHA 未改，upload SHA 與實際衍生檔相符，owner／request／素材欄位綁定正確。一般動漫與角色動漫使用相同來源，也得到相同的衍生上傳位元組。角色案保留原角色授權，新 v5 profile binding 與既有 current compatibility receipt 相符；沒有新增權限或捏造 golden。

每案只抽查第0、61、123格，並與各自舊版成果比較。新首格均保留完整來源與正常長寬比，舊版首格的明顯橫向拉伸未再出現。以亮度門檻12量測首格內容邊界，與收據記錄的補邊內容區相差不超過2像素；方圖內容為480×480、左右各補192像素，直圖內容為360×480、左右各補252像素。

中、尾格抽樣也未見舊版的明顯扁寬。一般動漫與寫實兩案的模型會將黑邊延展成場景；角色動漫案的抽樣則保留黑邊並產生揮手動作。因此黑邊不保證在整段影片維持不變，也不代表背景、人物或衣著保真已通過。

這些比較使用相同來源及所選輸出設定，供應商採隨機種子，不能視為固定種子的因果實驗。沒有檢查完整動畫或聆聽音訊，也沒有新增尾格單獨輸入、首尾雙輸入、寫實角色綁定、pipeline 或其他畫布的遠端生成驗證。實測結論限於上述三案的傳輸、所有權綁定、實際 UI 成果存取及抽樣比例改善。
