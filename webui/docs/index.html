GET STARTED

從一個工作流開始

ComfyUI 負責跑模型，WebUI 負責整理角色、素材與工作流。兩者安裝在同一台電腦，再用瀏覽器操作。

  1. 安裝並啟動 ComfyUI

    先依官方文件安裝適合自己 GPU 的 ComfyUI，在本機 127.0.0.1:8188 開啟。確認原生介面能連上，再安裝這套 WebUI。

    ComfyUI 官方安裝文件 ↗

  2. 安裝 WebUI，建立自己的密碼

    目前支援 Linux／Windows WSL2 與 Python 3.11 以上。下載 repo、建立虛擬環境、安裝依賴，再複製 .env.example 為 .env，填入 ComfyUI 路徑。

    git clone https://github.com/TED-H-com/Web_Comfyui.git
cd Web_Comfyui
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-webui.txt
cp .env.example .env
chmod 600 .env
.venv/bin/python run.py --check
.venv/bin/python run.py

    --check 用來確認環境與 ComfyUI 連線；通過後啟動並開啟 http://127.0.0.1:8190，設定至少 8 字元的管理密碼。

    完整安裝、路徑設定與排錯 ↗

  3. 選擇「可下載工作流」，先做小規模測試

    點卡片閱讀準備素材、執行順序與技巧。安裝列出的節點、下載符合模型家族的權重，放進自己 ComfyUI 的對應資料夾。

    本網站的「下載 JSON」可直接匯入原生 ComfyUI。本機 WebUI 的「載入 ComfyUI」會把工作流放進 webui-library 資料夾；開啟並確認模型、提示詞與素材後，再按 ComfyUI 的執行按鈕。

卡住時，從這裡看

連不上 ComfyUI
先確認 ComfyUI 已啟動。檢查 .env 的 COMFYUI_URL、COMFY_HOME，以及兩個程序是否位於同一個 WSL／Linux 環境。
缺少節點或模型
節點名稱與模型權重是不同的需求。「節點已具備」不代表模型已下載，也不代表 GPU 記憶體足夠。依工作流來源確認版本與權重。
沒有圖片、角色或 API 帳號
公開版從空白素材庫開始。請匯入自己的素材；需要外部 API 的功能，再設定自己的金鑰。本站沒有金鑰輸入欄，也不會連到你的本機服務。
想跑訓練或進階影片
MOSS 訓練、H3 與 NVIDIA RTX VFX 各有額外模型或環境需求。先看對應方案，避免直接替換目前可用的 ComfyUI 環境。
