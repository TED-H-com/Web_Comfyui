下載與本機安裝

實際生成，使用你自己的環境。

建議從一個符合現有模型與硬體的工作流開始，不必一次裝齊所有進階工具。

開始前需要

  • Linux / WSL2 · Python 3.11+
  • 獨立安裝並運行的 ComfyUI
  • 工作流對應的模型、節點與足夠硬體資源
  • 影音處理與聲音工具另有選用依賴

WSL2 請讓兩個程式運行於同一 Linux 環境。目前啟動器不支援原生 Windows 或 macOS。

下載原始碼 ZIP完整安裝與排錯指南 →

1. 先啟動 ComfyUI

在 ComfyUI 自己的 Python 環境中執行，確認節點編輯器可於 127.0.0.1:8188 開啟，並保持運行。

python main.py --listen 127.0.0.1 --port 8188
ComfyUI 官方安裝指南 ↗

2. 另開終端機，安裝 WebUI

git clone https://github.com/TED-H-com/Web_Comfyui.git
cd Web_Comfyui
python3 --version
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-webui.txt
cp .env.example .env
chmod 600 .env

首次安裝才複製 .env；更新時保留原本設定。模型、API 金鑰與個人素材不隨原始碼提供。

3. 設定路徑，檢查並啟動

編輯 .env 的 COMFY_HOME，使它指向你的 ComfyUI 目錄。啟動後開啟 http://127.0.0.1:8190，建立至少 8 碼的本機管理員密碼。

.venv/bin/python run.py --check
.venv/bin/python run.py

檢查只確認基本依賴與連線，不會下載模型或執行生成；通過檢查不代表所有工作流都能在你的 GPU 上運行。
